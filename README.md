# Прототип 3D-главной Oxygen

Запуск: из этой папки `python3 -m http.server 5180`, открыть http://127.0.0.1:5180. Нужен интернет: three.js грузится с jsdelivr.

- `index.html` — разметка и весь текст (HTML-слой, его читают поисковики).
- `main.js` — сцена: город, башня с вентиляторами, логотип и Искра из `assets/logo.svg`, сценарий скролла (`CAM`, `ISK` в `buildTimeline`).
- `assets/cases/` — кадры кейсов из BTL-портфолио, крутятся на экранах города.
- `assets/models/ozon-corp.glb` — если файл есть, он заменяет коллаж в зоне btl.

Тексты взяты из брендбука, прототипа Антона и портфолио; финальный копирайт — за Никитой.
